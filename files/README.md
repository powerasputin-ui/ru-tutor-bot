# Как запустить бота — пошагово для чайника

## Шаг 1. Получи токен Telegram-бота
1. Открой Telegram, найди бота **@BotFather**
2. Напиши ему `/newbot`
3. Придумай имя бота (например "Russian Tutor Bot") и username, оканчивающийся на `bot` (например `my_ru_tutor_bot`)
4. BotFather пришлёт тебе токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его, это `TELEGRAM_TOKEN`

## Шаг 2. Получи бесплатный ключ Gemini API
1. Зайди на https://aistudio.google.com/apikey
2. Войди через Google-аккаунт
3. Нажми "Create API key"
4. Скопируй ключ — это `GEMINI_API_KEY`

## Шаг 3. Залей код на GitHub
1. Зарегистрируйся на https://github.com если нет аккаунта
2. Создай новый репозиторий (New repository), например `ru-tutor-bot`, сделай его **Private**
3. Загрузи туда все файлы из этой папки (`bot.py`, `requirements.txt`, `Procfile`) — можно просто через кнопку "Add file → Upload files" в браузере, без командной строки

⚠️ ВАЖНО: НЕ загружай токены в код и не пиши их прямо в bot.py. Они передаются отдельно через переменные окружения (шаг 5).

## Шаг 4. Разверни на Railway (бесплатный хостинг)
1. Зайди на https://railway.app, зарегистрируйся через GitHub
2. Нажми "New Project" → "Deploy from GitHub repo"
3. Выбери свой репозиторий `ru-tutor-bot`
4. Railway сам увидит `Procfile` и `requirements.txt` и начнёт деплой

## Шаг 5. Добавь секретные ключи
1. В проекте на Railway зайди в раздел **Variables**
2. Добавь две переменные:
   - `TELEGRAM_TOKEN` = твой токен из шага 1
   - `GEMINI_API_KEY` = твой ключ из шага 2
3. Railway автоматически перезапустит бота с этими данными

## Шаг 6. Проверь, что бот работает
1. В Railway открой вкладку "Deployments" → последний деплой → "View Logs"
2. Ты должен увидеть строку `Bot started` — значит всё запустилось
3. Открой Telegram, найди своего бота по username и напиши `/start`

## Если что-то не работает
- Ошибка `TELEGRAM_TOKEN` не найден → проверь, что переменная в Railway названа ТОЧНО так, без пробелов
- Бот не отвечает → смотри логи в Railway на предмет ошибок (Error)
- Gemini выдаёт ошибку квоты → бесплатный лимит исчерпан на сегодня, попробуй завтра или другой ключ

## Известные ограничения этой версии (не забыть про них)
- История диалога хранится в оперативной памяти — если Railway перезапустит бота (а на free-тарифе это случается), история обнулится
- Нет базы данных пользователей — статистику по юзерам не собираем
- Только текст, без голосовых сообщений
- Бесплатный тариф Railway ограничен по часам работы в месяц — если бот "уснёт", напиши мне, разберём апгрейд
